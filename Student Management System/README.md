# Student Management System

## Project Overview
This project demonstrates GitHub version control using branches,
commits, pull requests, code reviews, and merge conflict resolution.

## Modules
- Student Information Module
- Attendance Management Module

## Tools Used
- GitHub
- Python
- Markdown

## Version Control Workflow
1. Create separate branches for individual modules.
2. Commit changes to each branch.
3. Create pull requests for code review.
4. Merge approved changes into the main branch.
5. Resolve merge conflicts when they occur.
